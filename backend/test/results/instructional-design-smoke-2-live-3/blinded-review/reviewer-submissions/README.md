# Reviewer submissions

Copy `../reviewer-submission-template.json` to `review-NNN.json` for each
assigned packet and replace `review-NNN` with the opaque packet ID. Submit only
completed response files to the researcher. Do not add condition, run ID,
provider, model, prompt, or private mapping fields.

The researcher will join responses to the private mapping after all blind
reviews are complete and then construct the internal `HumanEvaluation` records.
